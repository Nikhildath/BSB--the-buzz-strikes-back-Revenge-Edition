Hardware, Firmware, and PlatformIO Wars

The idea was simple and stupid: what if mosquitoes had to listen to their own annoying buzzing? We named it BSB — Buzz Strikes Back and started building.

Two ESP32 boards. One controls the trap (LED, speaker, zapper, sensors). The other handles the UI (OLED with emotic faces, touch buttons, web dashboard). They talk via ESP-NOW at 2.4GHz. No internet needed.

The workspace. Somewhere in this chaos is a mosquito trap.

The wiring was ambitious. ESP32 #1 alone needed 11 GPIO pins:

ESP32 #1 — Trap Controller GPIO 25 → Blue LED (via IRLZ44N MOSFET) GPIO 26 → IR Break-Beam Sensor GPIO 27 → HC-SR04 Trigger GPIO 14 → HC-SR04 Echo (voltage divider!) GPIO 5 → MAX98357A BCLK GPIO 18 → MAX98357A LRC GPIO 19 → MAX98357A DIN GPIO 22 → MAX98357A SD/EN (amp enable) GPIO 32 → Zapper MOSFET Gate GPIO 33 → Status LED ESP32 #2 — UI Gateway GPIO 21 → OLED SDA GPIO 22 → OLED SCL GPIO 26 → Touch Sensor 1 (emotion) GPIO 27 → Touch Sensor 2 (speaker toggle)

Firmware was written in two flavors: PlatformIO (ESP32 core 4.4.7) and Arduino IDE (core 3.3.11). Same chip, different callback signatures. The ESP-NOW receive callback uses esp_now_recv_info* on Arduino IDE but const uint8_t* on PlatformIO. We had to maintain both.

PlatformIO's .ino converter broke on large HTML strings in R"rawliteral(...)rawliteral" format. Fix: move all HTML to index_html.h. The enum : uint8_t syntax also broke it. Moved to #define.

We copied the ESP32-Eyes library (22 files) into the project for the emotic OLED display. The OLED shows only animated eyes — no text. Happy when idle, angry when buzzing, scared when lifted. The Face class drives a SH1106/SSD1306 via U8g2.

First breadboard prototype. OLED with emotic eyes. Blue LED glowing.

By the end of Day 1, both boards compiled cleanly. 36 files committed. ESP-NOW communication working. LED, IR sensor, touch buttons all functional. The speaker was silent. That was tomorrow's problem.

The Speaker Saga and Finishing Touches

Day 2 was supposed to be quick. Upload firmware, test speaker, done. The speaker had other plans.

We swapped from PAM8403 (PWM) to MAX98357A (I2S amplifier) for clean digital audio. The I2S driver installed fine. Pins configured. No errors. But complete silence.

The bugs we found:

  • Phase reset — sine wave recalculated from t=0 every buffer. No continuous waveform.
  • Volume overflow — speakerVolume was uint8_t (0-255) but multiplied by 8000. Integer overflow = garbage.
  • Missing amp enable — MAX98357A SD/EN pin needs HIGH to wake up. Not connected.
  • Wrong comm format — I2S_COMM_FORMAT_STAND_I2S should be STAND_MSB for MAX98357A.
  • Buffer too small — 256 samples caused underflow. Bumped to 512.
  • DMA stalls — only 4 DMA buffers. Increased to 8.

The final fix: a persistent speakerPhase accumulator that never resets, non-blocking i2s_write() with timeout=0, and GPIO 22 driving SD/EN HIGH on boot. 

float amplitude = ((float)state.speakerVolume / 255.0f) * MOSQUITO_VOLUME;
for (int i = 0; i < I2S_BUFFER_SIZE; i += 2) {
  float sample = sinf(state.speakerPhase) * amplitude;
  samples[i] = (int16_t)constrain(sample, -32767.0f, 32767.0f);
  samples[i + 1] = samples[i]; // stereo
  state.speakerPhase += 2.0f * PI * state.currentFreq / (float)I2S_SAMPLE_RATE;
  if (state.speakerPhase >= 2.0f * PI) state.speakerPhase -= 2.0f * PI;
}
i2s_write(I2S_PORT, samples, sizeof(samples), &bytes_written, 0);

Then: sound. A beautiful, annoying 450Hz mosquito buzz. The kind that makes you want to leave the room. Perfect.

Hardware working: speaker playing mosquito buzz, OLED emotic eyes, blue LED, ultrasonic sensor

After the speaker worked, we fixed the HC-SR04 lift detection (increased read rate from 5s to 1s), rewrote the README for TinkerHub Useless Projects, built a dark-themed journal for GitHub Pages, and added build photos and demo video.

The trap lures with blue LED, detects with IR, blasts their own buzzing back at them, zaps them, and shows a scared face on the OLED if you lift it. The web dashboard updates in real-time via WebSocket.

2 days. 2 ESP32 boards. 1 very annoyed mosquito.
